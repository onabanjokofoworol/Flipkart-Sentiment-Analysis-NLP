# Flipkart Sentiment Analysis Project

## Overview
This project classifies Flipkart product reviews into Positive, Negative, or Neutral sentiments.

## Dataset
The data used in this project can be found here: [Flipkart Dataset on Kaggle](https://www.kaggle.com/datasets/niraliivaghani/flipkart-product-customer-reviews-dataset)

## Project Link
* [Live Kaggle Notebook]](https://www.kaggle.com/code/onabanjokofoworola/notebookca31a84067))

## Results
Both Logistic Regression (96.93%) and Random Forest (96.94%) performed exceptionally well. Logistic Regression was chosen for final deployment due to its speed and interpretability.
